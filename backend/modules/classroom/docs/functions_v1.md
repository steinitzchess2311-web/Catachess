# Classroom 功能文档（简版）

## 1. 目标
- 为老师和学生提供一体化教学空间：班级管理、布置任务、学习跟踪、班级沟通。
- 与现有 `workspace`、`catchat` 联动，形成“布置-提交-反馈-复练”闭环。

## 2. 用户角色
- 老师：创建和管理班级、发布材料/作业/考试、查看统计、发布公告。
- 学生：接收任务、完成训练/考试、查看截止时间、联系老师与提交分享。
- 管理员（可选）：跨班运营管理、审计、导出数据。

## 3. 功能范围总览

### V1（最小上线）
- 班级管理：创建/解散班级，改名，拉人，踢人，设置管理员。
- 班级沟通：班级消息与公告（与 `catchat` 联动），学生可快速进入聊天。
- 任务中心：
  - 老师发布 train mode 作业。
  - 学生提交，老师查看完成状态与基础正确率。
- 工作区联动：
  - 创建有成员的班级后，自动出现 `My Classroom/{class name}/{student username}` 结构。
  - 学生在 classroom 中选择“share with teacher”后，内容进入对应目录。
- 日历与提醒：
  - 作业/考试截止时间展示（学生端临期/逾期）。
  - 老师端代办提示（谁提交了什么）。

### V2（能力扩展）
- 开局回放 trainer。
- 开局考试。
- 打谱 trainer（开局回放 + trainer 集成）。
- 上传系统增强（图片/PDF 更完整管理与复用）。

### V3（进阶训练）
- Lichess 战术体系接入（训练 + 测评）。

## 4. 教学内容类型

### 材料（学习型）
- 来源 1：workspace 直接导入。
- 来源 2：老师上传图片/PDF。
- 特征：可阅读，不计分。

### 作业（任务型）
- 类型：战术、开局、局面 trainer、老师上传图片/PDF。
- 可配置：截止时间、是否限时、可尝试次数。
- 结果：记录完成状态、得分/正确率、提交时间。

### 考试（评估型）
- 类型：战术考试、开局考试。
- 可配置：截止时间、限时、可尝试次数。
- 结果：评分与正确率统计。

## 5. 端侧功能

### 老师端
- 代办：学生提交、临期未交、逾期未交。
- 上传材料。
- 发布作业。
- 发布考试。
- 学生管理（成员/角色）。
- 作业入口（按 due date 卡片化展示）。
- 统计面板（整体正确率、题目级对错分布、学生对错分布）。
- 班级公告/广播入口（与 `catchat` 联动）。

### 学生端
- 代办中心（临期/逾期）。
- 公告区（最近老师消息，点击可进入聊天）。
- 作业入口（按 due date 展示）。
- 联系老师（支持 share folder with teacher）。

## 6. 补充必需能力（建议纳入路线图）
- 邀请与加入：
  - 班级邀请码/邀请链接（有效期、次数限制）。
  - 学生加入审批（自动通过/人工审核）。
- 教学运营：
  - 班级归档与恢复（防误操作）。
  - 班级数据导出（成绩、提交、出勤）。
- 教学闭环：
  - 讲评模式（高错题聚合）。
  - 学生学习画像（正确率趋势、完成时长、拖延风险）。
  - 错题复练任务自动生成。
  - 分层任务（A/B 难度）。
- 治理与安全：
  - 操作日志（成员、任务、分数、设置）。
  - 家长/旁听账号（只读，可选）。
  - 异常行为提醒（可选）。

## 7. 优先级建议
1. 先做：V1 全量 + 邀请/审批 + 班级归档恢复 + 操作日志。
2. 再做：V2 + 讲评模式 + 学习画像 + 错题复练。
3. 后做：V3 + 家长账号 + 风险提醒等高级治理功能。

## 8. 验收标准（简要）
- 老师可在 5 分钟内完成：建班、拉人、发一次作业、查看一次提交。
- 学生可在 3 分钟内完成：查看代办、进入任务、提交结果、给老师分享内容。
- 截止时间相关任务可被稳定标记为“临期/逾期”。
- 老师可按班级快速查看提交与正确率，不需要跨页面拼信息。
