## topic share visibility description removal

### 1. What text is unnecessary?
The visibility cards already have clear labels: Public, Private, and Shared. The secondary copy repeats the same meaning and adds visual noise.

Recommended answer: remove the secondary description lines from visibility cards.

### 2. Should the share behavior change?
No. Only the visual copy inside the cards should change.

Recommended answer: keep the same visibility values and API calls.

### 3. Should the card spacing stay the same?
No. Removing copy should reduce the card height slightly so the modal feels intentional rather than empty.

Recommended answer: keep icon plus label, with compact vertical spacing.
