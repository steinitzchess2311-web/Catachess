## topic product-grade email and workspace redesign

## questions
- What must change in the signup email?
  - Remove gradient/purple styling, use a restrained blue-white system, and include the product logo as a clear brand signal.
- What must stay stable in the signup email?
  - The verification code, expiration wording, fallback text template, and existing Resend send flow must keep working.
- What must change in workspace?
  - The current workspace browser should be visually redesigned after screenshot review, while preserving major workflows.
- Which workspace functionality is in scope to preserve?
  - Mode switching, search, path jump, sorting, creating folders/studies, opening folders/studies, drag-to-move, context actions, sharing, trash restore/purge, and guest limitations.
- What reference should guide the workspace redesign?
  - The existing study interface patterns: dense panels, clear workspace surfaces, restrained controls, and utilitarian product styling.
- What validation is required?
  - Local build, screenshots for desktop and mobile, and visual inspection for text overlap, blank states, and core control visibility.
