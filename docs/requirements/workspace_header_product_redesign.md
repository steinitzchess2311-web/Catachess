## Requirements
- Remove the visible top `Path` label and `root/...` path input from the workspace page.
- Preserve folder navigation through the existing breadcrumb and left folder tree.
- Keep the header compact enough to avoid the tall empty band shown in the current UI.
- Add clear header actions for `Create folder` and `Create study` in private workspace mode.
- Do not show create actions in public, shared, or recycle modes.
- Keep sort controls available, but make them visually secondary and grouped.
- Do not change node CRUD behavior, search behavior, folder tree behavior, study opening, drag/drop, or modal internals.
- Maintain responsive behavior for desktop and mobile.
