## 原始需求

- 用来复习开局。
- 要点：1 、必须有一个检测，只有 study 当中，起始局面是标准起始局面的，才会进入。2 、只有这个study 中，有存在 5 步以上的变化的（不一定是主变），才可以进入。3 、只可以在 study 中唤醒。是一个新的页面（后称"新页面"）。比如（只是计划）catachess.com/{study_id}/opening_trainer。
- 入口：当前的 study 右侧栏，那个trainer点击后，分为两个：1 、position trainer - 接原来的 trainer 。 2 、opening trainer - 接现在的新东西。每个 study 的这个新页面都不一样。

## Repertoire 构建

### 章节合并模式（用户可选）
- **按章节模式**：不合并，每个 chapter 独立按分拆逻辑处理，互不干扰。
- **合并模式**：把 study 中所有 chapters 合并成一棵大树，再统一分拆。
- 合并时用 **FEN 去重**（识别转置局面，更准确）。

### 白/黑视角
- 用户可自由切换（全局设置，不需要每个单元单独选）。
- 白方视角：只练白方走法，黑方由系统自动走。
- 黑方视角：只练黑方走法，白方由系统自动走。

## 分拆逻辑

### 分拆规则
- 在对手有多种应法的节点处分拆，每种应法 → 一个独立练习单元。
- **深度限制**：只在前 8 步（半步）以内的分叉处分拆；8 步以后的分叉不再产生新单元，并入上层单元作为子分支。

### 示例（白方视角）
```
单元1：对手走 1...e5 → 你需要掌握所有后续应对（含深层子分支）
单元2：对手走 1...c5 → 你需要掌握所有后续应对
单元3：对手走 1...e6 → ...
```

## 学习模式

### 三种模式
- **预习模式**：用户每一步先用 position trainer 猜，submit 后对比答案。（可 enable/disable）
- **学习模式**：系统先自动演示走法，然后退回，用户跟着摆，摆对了继续。
- **考试模式**：用户走自己视角的棋，系统自动走对方视角（从初始局面开始）。

### 考试模式细节
- 对手有多个应法时，**随机选一条**，保证每次练习路径不同，更接近实战。
- 用户走错（走了 repertoire 以外的棋）：提示错误，不直接锁定落子。

### 错题循环（参考 Chessable）
- 做错一次 → 需连对 3 次才标记为掌握。

### 练习起点
- 每个单元从**初始局面**开始走，保持完整上下文感。
